# 径迹 UI 重新设计方案

## 设计理念

**极简主义 + 内容至上**

首页追求极致简约——只有风景、标题、搜索框，让自然之美成为唯一的主角。详情页参考 AllTrails 的信息密度和层次感，把所有关键数据高效呈现。

**核心原则：**
- 首页：少即是多，高级感来自留白和克制
- 详情页：信息密度高但层次清晰，一屏看完核心数据
- 无用户系统，无导航栏，纯粹的工具型产品

### 设计规格

**背景轮播：**
- 全屏高度 (100vh)，图片 cover
- 暗色叠加层 (rgba(0,0,0,0.35)) 保证文字可读
- 自动轮播 8 秒，手动切换
- 切换动画：淡入淡出 2.5s

**品牌标题：**
- "径迹" — 48px, font-weight 700, 白色
- 居中，带轻微文字阴影

**副标题：**
- "发现你的下一次冒险" — 18px, 白色 80% 透明度
- 居中

**搜索框：**
- 药丸形 (border-radius: 9999px)
- 宽度: max-width 560px, 居中
- 背景: 白色, 阴影: large
- padding: 16px 24px
- 字号: 16px, 颜色: #111827
- placeholder: "搜索线路名称、地区..."
- focus: 边框变为 #16A34A

**搜索结果下拉：**
- 白色卡片，圆角 12px，阴影 large
- 最大高度 320px，可滚动
- 分组显示：省份 / 线路
- 每项 padding 12px 16px，hover 灰色背景

**无其他元素：**
- 无导航栏
- 无统计数字
- 无热门标签
- 无页脚
- 背景图就是一切

## 天气数据

### API: Open-Meteo

- 免费，无需 API key
- 全球覆盖，包括中国
- 文档: https://open-meteo.com/en/docs

### 请求格式

```
GET https://api.open-meteo.com/v1/forecast
  ?latitude={lat}
  &longitude={lng}
  &daily=temperature_2m_max,temperature_2m_min,precipitation_probability_max,precipitation_sum,windspeed_10m_max,winddirection_10m_dominant,weathercode
  &timezone=Asia/Shanghai
  &forecast_days={天数}
```

### 返回字段

| 字段 | 说明 | 用途 |
|------|------|------|
| temperature_2m_max | 最高温°C | 服装分层 |
| temperature_2m_min | 最低温°C | 睡袋/保暖 |
| precipitation_probability_max | 降水概率% | 雨具决策 |
